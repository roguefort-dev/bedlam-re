# bedlam-re

Unofficial decompilation + modern reimplementation project for **Bedlam**
(GT Interactive Software / Mirage, 1996) in Rust.

- Goal: smooth, stable, cross-platform (Linux/Windows/macOS), time-based engine,
  modern controls, original bugs fixed. Runs the original game assets.
- `docs/PLAN.md` — the plan. `docs/GROUNDWORK.md` — verified facts about the game.
- `game-data/` — read-only reference copy of the original game (git-ignored).
- `engine/` — Rust workspace (created in Phase 3). `tools/` — RE/inspection tooling.
- `goldens/` — reference captures for parity testing.
- Not affiliated with GT Interactive/Mirage. No original assets are redistributed.
